Core Features

Why SMS Query Outperforms Standard SMS Apps

Built specifically for power users who receive hundreds of verification codes, bank receipts, and client messages across two separate SIM lines.

Feature 01 // Multi-Attribute Filtering

Never scroll endlessly through weeks of messages again.

Most default messaging apps offer only simple text searches that match partial words across years of history. SMS Query lets you narrow down results instantly with four simultaneous parameters.

  • Targeted Senders: Isolate messages from Amazon, your bank, or specific contacts.
  • Date Intervals: Restrict queries between any two calendar days.
  • Time-of-Day Windows: Find codes received only during office hours (e.g. 09:00 to 17:00).
Feature 02 // True Dual-SIM Hardware

Two SIM cards. One seamless, unified workflow.

Standard SMS applications often default to SIM-1 without checking your active hardware configurations. SMS Query actively reads Android's `SubscriptionManager` API to present real carrier names, signal indicators, and distinct slot tags.

  • Independent Line Selection: Pick SIM 1 or SIM 2 for both sending and filtering.
  • Hardware Carrier Visibility: View active subscriptions (e.g., T-Mobile 5G vs Vodafone LTE).
  • Color-Coded Message Pills: Instantly distinguish personal and work messages.
Feature 03 // Default SMS Handler

Full system integration. Zero compromises.

SMS Query includes all necessary Android `ROLE_SMS` receivers, headless services, and MMS adapters required to operate as your system-wide default messaging app on Android 7.0 through Android 16.

  • System Inbox Sync: Writes directly to Android `Telephony.Sms.Inbox` for 100% interoperability.
  • On-Device Room DB: High-performance local index ensures search takes under 5 milliseconds.
  • Zero Cloud Telemetry: Your messages never touch an external cloud server.
